# Source and asset credits

Adapted from the user's local checkout of [bauer-code/Brass-Tasks](https://github.com/bauer-code/Brass-Tasks), inspected at commit `36099bd84390fc38d116d20cbc5a666f9c50666d`. The checkout was used read-only.

The typewriter and clock visual styling, icon, Pomodoro state machine and its original unit tests, and sound implementation are derived from that desktop app. The workspace shell, responsive adaptation, browser data model, library, Markdown browser workflows, backup/restore, and journal integration were built for this separate repository. The source repository did not contain an explicit project license in the inspected checkout, so this project does not assign a new license to the inherited code.

- **Press Start 2P:** font by CodeMan38, distributed under SIL Open Font License 1.1. The font and license are bundled in `public/assets/`.
- **Clock recordings:** Joseph SARDIN, BigSoundBank / LaSonothèque, CC0. Full source links and licensing information are preserved in [the audio credits](../public/assets/audio/CREDITS.md).
- The icon is the combined Brass & Tasks typewriter and clock icon from the original application.

No remote font, image, analytics, or CDN services are used by the deployed app.
